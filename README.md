# Анализ лояльности пользователей: заказы билетов «Афиша»

## Задача

На основе выгрузки заказов билетов (июнь–октябрь 2024) оценить вовлечённость
пользователей (возврат после первой покупки), найти факторы, влияющие на
повторные заказы, и сформулировать рекомендации для CRM.

## Запуск

1. Клонируйте репозиторий и подготовьте окружение:

```powershell
git clone https://github.com/Prokl7774/mle-analiz-loyalnosti-polzovatelej.git
cd mle-analiz-loyalnosti-polzovatelej
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

2. Настройте доступ к базе: скопируйте `.env.example` в `.env` и заполните
   параметры подключения (хост, порт, имя базы, пользователь, пароль).
   Сам `.env` исключён из репозитория через `.gitignore`.
3. Подготовьте данные в папке `data/`:
   - `orders.csv` — выгрузка заказов из базы `data-analyst-afisha`
     (схема `afisha`, таблица `purchases`, джойн с событиями, городами
     и регионами), срез: mobile/desktop, без событий типа «фильм»;
   - `final_tickets_tenge_df.csv` — дневные курсы тенге к рублю
     (колонки `data / nominal / curs / cdx`), источник — <ССЫЛКА НА ИСТОЧНИК КУРСОВ>.
4. Запустите анализ: `python main.py` — итоговый отчёт выводится в консоль.

## Подготовка данных

- Исходный срез: 290 611 строк, 21 933 пользователя.
- Конвертация валюты: 5 073 заказа в тенге пересчитаны в рубли по курсу
  на дату заказа (левый merge по нормализованной дате — заказ получает
  курс именно своей даты).
- Очистка:
  - неявные дубликаты (одинаковый заказ под разными order_id): ключ —
    пользователь, точное время заказа, устройство, сервис, event_id
    и выручка в рублях; удалено 42 строки;
  - отрицательная выручка (возвраты/корректировки): удалено 381 заказ;
  - хвост выручки выше 99-го перцентиля (порог 2 628.4 руб);
  - аномальные аккаунты: порог — 99-й перцентиль числа заказов (150);
    исключено 217 пользователей (1.00%).
- Итог: 21 483 пользователя.

## Основные результаты

- **Возврат: 61.3%** (13 165 из 21 483 пользователей).
- Retention по типу первого события: лидеры — выставки (64.3%) и театр
  (63.5%), худший — спорт (54.9%); концерты — 61.8%.
- Точка входа и точка удержания не совпадают: концерты дают 44.7% первых
  заказов, но удерживают на уровне среднего; театр — 19.8% входа и 63.5%
  возврата («узкий, но липкий» вход).
- Desktop возвращается чаще mobile: 63.6% против 60.8%.
- Размер покупки — не предиктор возврата: средняя выручка заказа у групп
  «1 заказ» и «2+ заказов» почти равна (552.7 против 551.8 руб), различаются
  только медианы (388.7 против 503.3 руб).
- Когорты: месячный retention второй покупки — 25–27% для когорт
  июля–сентября; у июньской когорты аномально высокие 45.7% — вероятный
  эффект границ окна выгрузки. NaN в правом верхнем углу тепловой карты —
  месяцы, ещё не наступившие в окне наблюдения.

## Гипотезы

Гипотезы о возврате проверялись с фиксацией направления эффекта.
Гипотеза «после спорта возвращаются чаще» **опровергнута**: различие долей
статистически значимо, но направлено в обратную сторону — возврат после
спорта ниже, чем после концертов. Остальные гипотезы подтверждены.

| Гипотеза | Статистика | Вердикт |
|---|---|---|
| «После спорта возвращаются чаще» | спорт 54.9% (n = 765) vs концерты 61.8% (n = 9 607), z = −3.76, p = 0.0002 | опровергнута: возврат после спорта ниже |
| Крупные регионы возвращают чаще | топ-2 региона 62.6% (n = 10 756) vs остальные 59.9% (n = 10 727), z = 4.12, p < 0.001 | подтверждена |
| Размер региона vs retention | Спирмен ρ = 0.31, p = 0.005 | подтверждена: слабая положительная связь |
| День недели первой покупки влияет на возврат | хи² = 14.9, df = 6, p = 0.021 | подтверждена: связь значима, но эффект мал (размах 3.3 п.п.) |

По дню недели лучшие дни — суббота (62.8%) и понедельник (62.6%),
худшие — четверг (59.5%) и пятница (59.9%).

## Корреляции (phi_k с числом заказов)

Сильнее всего с числом заказов связан регион первого заказа (φ_k = 0.123),
далее день недели (0.053) и сервис (0.042); тип события (0.028), выручка
первого заказа (0.021) и устройство (0.016) — слабо, число билетов — 0.000.
После исключения аномальных аккаунтов региональная связь перестала быть
замаскированной: экстремальные профили размывали картину.

Внутри сегментов: у «1 заказа» и «2 заказов» связи не определены (нет
разброса), в сегменте «3–4 заказа» связей нет, а в сегменте «5+ заказов»
регион резко выходит вперёд (φ_k = 0.55), далее день недели (0.12) и
устройство (0.10). У активных покупателей дальнейшую частоту заказов
дифференцирует география первого заказа.

## Рекомендации

- Главный рычаг вовлечённости — тип события, а не размер чека: спорт —
  один из худших сегментов по удержанию, для него нужны отдельные
  механики возврата.
- Сегментация по типу события и региону, не по сумме первого заказа.
- Первые коммуникации (welcome-цепочки) ставить на субботу и понедельник;
  день недели — фактор второго порядка, отдача несопоставима с работой
  по типу события и региону.
- Аномальные профили вывести в отдельный контур после проверки их природы.

## Ограничения

- Окно наблюдения ~5 месяцев: долгосрочные эффекты и поздние когорты
  не видны в полном объёме.
- Сезонность неотделима от типа события (эффект «ёлок летом»).
- География синтетическая; регион первого заказа — регион мероприятия,
  а не проживания пользователя.
- φ_k измеряет силу связи, а не причинность; выводы не проверены
  на новых данных.
