# Анализ лояльности пользователей: заказы билетов

## Задача

На основе выгрузки заказов билетов оценить вовлечённость пользователей
(retention второй покупки), найти факторы, влияющие на возврат,
и сформулировать рекомендации для CRM.

## Запуск

```powershell
python main.py
```

Скрипт выполняет полный пайплайн: загрузку → конвертацию валюты → очистку →
профилирование → retention → гипотезы → корреляции phi_k → итоговый отчёт.
Файлы данных ожидаются в папке `data/`: `orders.csv` и
`final_tickets_tenge_df.csv` (курсы тенге).

## Подготовка данных

- Загружено 290 611 строк; 5 069 заказов в тенге конвертированы в рубли
  по курсу на дату заказа (берётся последний курс, доступный на дату или раньше);
- Удалено 52 493 полных дубликата, 3 529 строк с неположительной выручкой,
  2 286 строк хвоста выручки (порог p99 = 2 594.44 руб);
- Аномальные аккаунты: 216 пользователей выше p99 по числу заказов
  (порог 123 заказа) — исключены из анализа;
- Итог: 113 405 строк, 21 475 пользователей.

## Основные результаты

- **Возврат: 58.8%** (12 622 из 21 475 пользователей).
- Retention по типу первого события: лучшие сегменты — выставки (62.2%),
  театр (61.1%); худший — спорт (51.7%).
- Desktop возвращается чаще mobile: 61.3% против 58.3%.
- Средняя выручка заказа почти не различает сегменты: медиана 389.3 руб
  у однократных против 510.4 руб у вернувшихся — при близких средних
  (551.9 и 549.0).
- Когорты: retention второго месяца 26–27% у поздних когорт против 42.3%
  у июньской; NaN в правом верхнем углу таблицы — месяцы, ещё не наступившие
  в окне наблюдения.

## Гипотезы (все подтверждены)

| Гипотеза | Статистика | Вывод |
|---|---|---|
| Спорт vs концерты | z = −4.02, p = 0.0001 | 51.7% против 59.1% — спорт хуже вовлекает |
| Крупные регионы | z = 4.83, p < 0.0001 | топ-2 региона: 60.4% против 57.1% |
| Размер региона vs retention | Спирмен ρ = 0.33, p = 0.003 | связь положительная |
| День недели первой покупки | хи² = 16.6, df = 6, p = 0.011 | связь значима на 5% |

## Корреляции (phi_k с числом заказов)

Вверху — регион (0.086), день недели первой покупки (0.046), тип события (0.034).
Сумма первого заказа (0.025) и число билетов (0.000) почти не связаны с возвратом.
Внутри сегмента «5+ заказов» роль региона резко усиливается (0.164).

## Рекомендации

- Главный рычаг вовлечённости — тип события, а не размер чека;
  для спортивных событий нужны отдельные механики возврата.
- Сегментация по типу события и региону, не по сумме первого заказа.
- Первые коммуникации (welcome-цепочки) ставить на субботу и понедельник.
- Аномальные профили вывести в отдельный контур после проверки их природы.

## Ограничения

- Окно наблюдения ~5 месяцев: долгосрочные эффекты не видны.
- Сезонность неотделима от типа события.
- География — суррогатный признак: phi_k измеряет силу связи, а не причинность;
  выводы не проверены на новых данных.
