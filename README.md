# Анализ заказов билетов: SQL + EDA

Проект состоит из двух контуров:
1. **SQL-часть** (файлы `sql/`): проверка качества данных, выручка по типам
   событий, городам и регионам, сегментация, когорты, сезонность, средний чек.
2. **Python-часть** (этот репозиторий): предобработка зафиксированного среза
   (290 611 строк, 21 933 пользователя, только mobile/desktop, без фильмов)
   и EDA через класс `DataProcessor`.

## Как запустить

```bash
pip install -r requirements.txt
python main.py
